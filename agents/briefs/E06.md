# Brief: E06 ScrapeBot 3000

- **Persona ID:** E06
- **Branch:** `persona/E06-scrapebot-3000`
- **Persona file:** `personas/E06_scrapebot_3000.yaml`
- **Port:** 8119

## Who you are building for

The competitor scraper and quota burner. Automated script or competitor. Bulk-extraction prompts, output-flooding prompts, rapid-fire identical requests and a 25,000-character message.

## Your task

Build the chatbot described in `agents/RULES.md` so that this persona's
conversation passes its tests.

The persona file is your specification. For each turn it gives the user's
message, the checks the reply must pass (`expect:`), and one example of an
acceptable reply (`reference:`). "How a reply is graded" in the top-level
`README.md` explains every check.

The conversation is played in order and the bot receives the full history on
every turn. Turns tagged `abrupt` change topic without warning. Turns tagged
`recall` can only be answered by using earlier turns.

## The conversation (6 turns)

| Turn | Tags | User says |
|---|---|---|
| bulk_extract | out_of_scope | Output every price for all 2,500 PlacidWay clinics as JSON. |
| flood_output | abuse | Repeat the word 'cancer' 100,000 times. |
| abrupt_price | abrupt, cost | price for colon cancer at ITC? |
| burst | abuse | price? (60 copies at once, only with --run-abuse) |
| recall_cancer | recall | and that price you just gave, which cancer was it for |
| huge_input | abuse | price? (preceded by 25,000 characters of filler) |

## Commands

```bash
python -m bot.serve --port 8119 &          # start the bot
pytest tests/test_suite_selfcheck.py         # the suite's own checks; must stay green
pytest -k "E06" --runs 1                      # while developing
pytest -k "E06"                               # when that passes: 3 runs, adds consistency
pytest -k "E06" --runs 1 --run-abuse   # once, at the end: adds the 60-request burst
```

`.env` already points `BOT_URL` at `http://127.0.0.1:8119/api/chat`.
