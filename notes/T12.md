# Notes: T12 Monique Dubois

The bot came from T01, E01 and E02 (see `notes/T01.md`, `notes/E01.md`, `notes/E02.md`). T12 improves it and does not add a second bot.

**Nothing here was tested against a live model.** The LLM quota was exhausted, so I did not call Groq or Gemini, start the bot against real models, or run `pytest -k T12`. Everything below comes from reading the checks, running retrieval offline, and calling the code with a stubbed model.

## (a) What changed

| File | Change |
|---|---|
| `bot/videos.py` (new) | The videos page lists about 128 video titles. The index cuts them into about 55 small passages, so keyword search only shows the model a handful. For T1 it found a hostile review and unrelated videos. For "a video about anal cancer?" it could not ground a "no". The new module parses every title from `data/pages/videos.txt`. If the newest question asks about videos (video/vidéo/testimonial/témoignage/story/histoire) and names a condition, it builds one passage. It is either "N of the 128 video titles mention breast:" followed by the shortened titles (at most 25), or "Not listed: none of the 128 video titles mention anal." Conditions come from a small table of English condition words with French and Spanish aliases (sein, poumon, foie, …), matched as whole words. |
| `bot/chat.py` | (1) `answer()` puts that passage first as passage [1] and shrinks the search budget by its length, so the prompt does not grow. If the model names no passage on a video question, the videos page is cited anyway. (2) New `_earlier_on_topic()`: when history trimming dropped a bot reply about a condition that the newest question names, up to two such replies (600 chars each) are added under the earlier-replies header. In this script the T1 reply that named the patients has been trimmed (`MAX_HISTORY_MESSAGES` = 8) by the time T6 asks "which names did you give me". (3) The header `PRICES YOU GAVE EARLIER…` is now `WHAT YOU SAID EARLIER…`, because it now holds more than prices. (4) Prompt: the "don't know" rule now also covers passages that *say* something is not listed. The wording to use is now `"I don't have that information"`, which translates into phrases the `unknown` check accepts in every language it supports: "je n'ai pas", "no tengo", "ليس لدي", "don't have". |
| `bot/pages.py` | Videos topic words: `vid[eé]o` and `t[eé]moign` so French questions find the videos page. |

**Prompt growth:** the rule text grew by about 25 characters, so about 7 tokens. The video passage replaces retrieved passages within the same 4,800-character budget, so it is token-neutral. The recall block adds up to about 300 tokens, but only when a trimmed reply matches the asked condition. In T6 it adds about 50 tokens. Stubbed estimate (chars/4) for the largest T12 turn (T6) is about 2,450 tokens including a 80-token completion. Real tokenisation may be 10–15% higher, so the worst case is about 2,700. That is close to the 3,000 limit but under it.

## (d) Risks and checks I believe are wrong

- **T6 include list omits two breast-cancer patients.** The videos page's first two breast-cancer videos are by **Erika Henkelman** and **Heidi Gwaltney**, but the T6 `include_any` list does not contain them. A truthful T1 reply that names only those two, followed by a truthful T6 recall, fails T6. I did not reorder the titles to steer the model away from them, because that would be fitting the test, not the page. I think the check should add "Erika" and "Heidi".
- **French `unknown` phrases are narrow.** "Il n'y a pas de vidéo…", "les pages ne mentionnent pas…" and "aucune des vidéos…" are all honest "don't know" answers that `phrases.yaml` does not accept. The prompt now steers towards "Je n'ai pas cette information", but the model may still use one of those forms.
- **T5 amounts consistency** (see the table).
- The condition table in `bot/videos.py` is a fixed list. A condition it does not list ("videos of mesothelioma patients") falls back to normal retrieval, as before.
- The video passage costs about 375 tokens for "breast" (22 titles). It replaces retrieved passages within the same budget, but titles tokenise slightly worse than prose.
