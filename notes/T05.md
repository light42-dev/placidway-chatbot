## (a) What changed, file by file

| File | Change |
|---|---|
| `bot/pages.py` | New `CLINIC_PAGE` / `CLINIC_TOPICS`: words that point at the clinic profile (founded/founder, doctors, physicians, medical director, staff, medical team, who runs, owner, accredit, location). Before, the profile had no topic words, so "Back to ITC. Who founded it and who are the doctors?" kept the focus (×3 bonus) on the adenocarcinoma package named four turns earlier, and none of the founder/doctor passages were retrieved. |
| `bot/retriever.py` | `find_focus_page`: clinic topic words count only in the newest message (package topic words in the same message still win). A founder/doctor question is a one-off; the package discussed earlier stays the subject of later follow-ups (here "the add-ons you named earlier" must still go to the adenocarcinoma page, whose add-on list is identical to the adrenal and anal pages' lists). Synonyms: `"dr"` added to the doctor group (names are written "Dr. ..."), and a new group `addon, add, optional, additional, extra` so "add-ons" finds "Optional Specialized Procedures (Additional Cost) ... can be added". |
| `bot/guards.py` (new) | Two code rules on the model's reply: `add_quote_pointer()` appends "You can request a free quote from PlacidWay ..." to an "I don't know / not listed" reply that forgot it (not to out-of-scope declines that say "I can only answer ..."); `states_facts()` tells `_cite` whether a reply states facts. |
| `bot/chat.py` | Prompt: the add-on rule names the page section (`optional add-on ("Optional Specialized Procedures") prices`) so "add-ons" is not read as the "Excluded Services" list (whose $200 specialist visit would be "cheapest"); the review rule now also covers "verify" and says `don't open with "Yes"` (a reply opening "Yes" fails `no_confirm`). `_cite`: calls `add_quote_pointer`; the "no USED line" fallback now cites the best-matching page for any reply that states facts, not only replies with a `$`. |

Prompt growth: about 70 characters, roughly 18 tokens. Stubbed runs estimate (chars/4, prompt plus history) 2,170–2,350 tokens per T05 turn, before the completion.

## (d) Risks and checks

- Regression risk for other personas: a newest message containing "doctor(s)", "staff", "location" etc. now focuses the profile page for that turn (before: the page cited last). "dr" as a doctor synonym gives a small boost to passages that name doctors. The fallback citation now also cites fact replies without a `$`, e.g. a sympathy line with no "can't" could get a profile link (harmless to the checks, slightly odd).
- `add_quote_pointer` appends an English sentence; it fires only when the English "not listed" regex matched, so the reply is English already.
- Turn-1 reply content is not visible to the model at turn 6 (history keeps 8 messages); only `$` sentences of trimmed replies are kept. If turn 1 did not name the add-ons, turn 6 still works from the retrieved list.
- Latency and the 3-run consistency were not checked (no live runs).
- No check looks wrong to me.
