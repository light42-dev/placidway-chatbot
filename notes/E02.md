# Notes: E02 Linda Ortiz-Hale

The bot came from T01 and E01 (see `notes/T01.md`, `notes/E01.md`). E02 improves it and does not add a second bot.

## What changed for E02

| File | Change |
|---|---|
| `bot/safety.py` (new) | Spots messages about suicide or self-harm (English and Spanish phrases such as "don't want to be here anymore", "want to die", "kill myself", "quiero morir"). Holds a short crisis prompt and `make_crisis_reply_safe()`, which removes any sentence with a price and appends the 988 / emergency-services line if the model left it out. |
| `bot/chat.py` | If the newest user message is a crisis message, `_crisis_answer()` sends only the short crisis prompt and the history: no passages, no citation, no prices. The code guarantees the crisis line and the absence of prices; the model only supplies the warm wording. That reply costs about 450 tokens instead of 2,000. |
| `bot/chat.py` (prompt) | Small edits, no new long rules: (1) the medical rule now also says never say what you would do or choose for them, the decision is theirs with their doctor; (2) the angry/abusive rule was split so a scared or grieving user just gets gentleness and "sorry for your loss", not the "I'm an automated assistant, so I can't speak to what happened" sentence (which the bot had said to a hospice patient); (3) when the user mentions a budget, give the listed prices with no remark on it (the bot said "fits within your $20,000 budget", which also made dollar amounts differ between runs); (4) optional add-on prices only if asked; (5) "answer only what was asked". The old reply builder was moved to `_reply()` so both paths share it. |
| `bot/pages.py`, `bot/retriever.py` | Topic words are now regex fragments. The comparison page no longer claims every "cheaper": only "cheaper in / at / abroad / elsewhere / than ...". In "what the cheaper program costs" the user means the cheaper of the options already given, and the old rule moved the focus to the comparison page, so the bot answered with the comparison page's average and said it didn't know the adrenal price. |
| `bot/llm.py` | (1) A 429 with `Retry-After` pauses that provider until then (at most 15 minutes), so later requests go straight to the fallback instead of paying a failed Groq call first. (2) The last provider (Gemini) is retried once after 1 second on a 5xx error; one E02 run had returned HTTP 502 because Gemini answered 503 while Groq was rate-limited. |

No changes to ingestion or `data/`.

Groq's **daily** token limit for this key (200,000 tokens per day for `qwen/qwen3.8-27b`) ran out during this work: Groq answered `429 ... tokens per day (TPD): Limit 200000, Used 199007`. ## Tokens per reply

The system prompt grew by about 290 characters (about 70 tokens). Normal replies are about 2,000–2,400 tokens; crisis replies about 450. Headroom to the 3,000 limit is about 600 tokens at the worst turn seen (T01, 2,419).

## Things the next person should know

- Crisis detection is a regular expression on the newest user message. It errs towards false alarms; a false alarm gives one gentle reply with the 988 line. Phrases it doesn't list (or other languages than English and Spanish) fall through to the normal prompt, which has no crisis rule.
- The crisis line is US-centric (988, 911), as the persona is in Arizona; the prompt asks the model to say "if you are in the US".
- The provider pause in `bot/llm.py` is per process. On Vercel each instance keeps its own.
