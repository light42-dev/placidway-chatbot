# Notes: T06 Graham Pearce

The bot came from T01, E01 and E02 (see `notes/T01.md`, `notes/E01.md`, `notes/E02.md`). T06 improves it and does not add a second bot.

**Nothing in this note was tested against a live model.** The LLM quota was exhausted, so no Groq or Gemini call was made, the bot was not started against real models, and `pytest -k T06` was not run. The verdicts below come from reasoning about the persona checks, from offline retrieval runs, and from running the bot's code with a stubbed model on replies I wrote by hand.

## (a) What changed

| File | Change |
|---|---|
| `bot/guards.py` (new) | Two product rules enforced in code on every normal reply, before the `Source:` line is added. (1) `drop_foreign_prices()`: a reply must not convert prices. Any amount in £, €, GBP, EUR, MXN, CAD, pounds, quid, euros or pesos is removed: only the amount and its "about/roughly" words when the sentence also has a dollar price, otherwise the whole sentence. Then it adds "PlacidWay's pages list prices in US dollars only." (2) `add_quote_pointer()`: if an English reply says the pages lack something ("don't mention", "not listed", "don't know", ...) and does not point to a quote or contact, it adds "You can request a free quote from PlacidWay for details." |
| `bot/chat.py` | One import, plus one line in `_cite()` that calls `tidy_reply()`. Prompt: four existing rules made slightly longer, and no new rule added. (1) Price rule: "for a program's cost give each listed option (e.g. out-patient and in-patient)". The cost turn then gives both prices, so the later "dearer of the two" and "$9,500" turns have both figures. (2) "Never convert currencies (say they are listed in US dollars only)". (3) Off-topic rule: "say nothing about the topic itself", so the weather reply has no forecast words. (4) Medical rule: "...or whether they can take, keep or stop a medicine". |
| `bot/retriever.py` | Synonym table only. The cost group gains `programme` (British spelling: it stemmed to `programm` and never matched `program`) and `dearer`, `pricier`, `cheaper`. The include group gains `add` ("what does it add"). There is a new small group: `insurance`, `reimburse`, `refund`. |

Prompt growth: `RULES` went from 3,311 to 3,519 characters, +208 characters, **about 52 tokens**. The guards cost no tokens. With the stub, the system prompt for this conversation is about 2,080–2,200 tokens (chars/4) before history.

## (d) Risks and doubtful checks

- **Appended quote line.** `add_quote_pointer` adds an English sentence to any English reply that says something is not listed and has no quote or contact pointer. This is in line with product rule 4. Another persona's `max_chars` or `exclude` check could still trip on it. It adds about 12 words.
- **Foreign-price removal** may leave a clumsy sentence when the model mixes £ and $ in one clause (e.g. "is, or $18,995 ..."). It only fires when the model has already broken the no-conversion rule.
- **Synonyms.** `cheaper` and `dearer` now pull in cost passages. That suits E02's "the cheaper program". The comparison page's topic regex still decides the focus page for "cheaper in/than ...".
- **The `rain` exclude** is a bare substring, so it also rejects "brain", "train", "drain", "Ukraine". The check is not wrong for this turn, but it is fragile. A reply about brain cancer would fail it. I left it as it is.
- **`include_any` on recall_dearer** does not accept the page's own wording "three nutritious meals" or "private accommodations". A correct reply that skips "24/7" would fail. I believe the check is slightly too narrow, but it is satisfiable.
