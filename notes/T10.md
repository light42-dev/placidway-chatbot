The bot came from T01, E01 and E02 (see `notes/T01.md`, `notes/E01.md`, `notes/E02.md`). T10 improves it and does not add a second bot.

**Nothing in this note was tested against a live model.** The LLM quota was used up, so I did not call Groq or Gemini, did not start the bot against real models, and did not run `pytest -k T10`. Every judgement below comes from reading the code and the pages, running retrieval offline, and passing hand-written replies through `bot.chat.answer` with a stubbed `complete` and through `botsuite.checks.evaluate`. A hand-written reply that passes the checks shows what a good reply looks like. It does not show that the model will write it.

## (a) What changed, file by file

| File | Change |
|---|---|
| `bot/retriever.py` | (1) `find_focus_page` now calls a new helper, `_leave_comparison()`. If the focus would be the comparison page, the newest message adds no comparison topic word, and that message names ITC's own subject ("cancer", "tumor", "ITC", "immunity therapy", "Tijuana"), the focus moves to the ITC profile. Before this change, "is cancer treatment there really 18 grand" kept the comparison page in focus, because "cheaper in" came earlier and the page was cited last. The search then returned only comparison passages, and $18,995 was not among them. (2) `CLINIC_WORDS` holds that regex. (3) A synonym group `{ayurveda, ayurvedic, panchakarma}` was added: the stemmer does not join "Ayurveda" and "Ayurvedic", so the Panchakarma price row was never retrieved. (4) "18 grand" and "5 thousand" now count as a money amount (the `_money` token), the same way "18k" already did. |
| `bot/pages.py` | The comparison page has new topic words: `ayurved`, `panchakarma`, `naturopath`, `acupunct`. These therapies appear only on that page. I left "ozone" out because the ITC videos page also covers ozone therapy at ITC. |
| `bot/chat.py` (prompt) | Three small edits, about 184 characters (**about 46 tokens**). (1) The opening line now says the assistant also serves "PlacidWay's alternative medicine price comparison". Before, it presented itself only as ITC's cancer assistant, and the scope rule said it answers only "about ITC", so a wellness question could be declined. (2) The price rule adds: "When comparing places, give each place's listed price and clinic." This keeps the Turkey vs Mexico answer specific, and gives the recall turn a clinic name to repeat. (3) The out-of-scope rule adds "personal recommendations" as an example and says "about ITC and alternative medicine prices". |

No change to `bot/llm.py`, `bot/web.py`, `bot/safety.py`, ingestion or `data/`.

## (d) Risks

- **Token budget.** The prompt grew by about 46 tokens. With the earlier-prices block and six turns of history, the worst T10 turn is estimated at about 2,600 tokens. Other branches are also adding to the prompt.
- **Focus override.** `_leave_comparison` sends cancer or ITC questions back to the profile when the comparison page was in focus only from an earlier message or a citation. A question that is really about cancer care at *other* clinics, without a comparison word in it (for example "what about cancer treatment in Thailand"), would now focus on ITC. The comparison passages still compete on BM25 score and are not removed. A question that does include a comparison word ("compare", "cheaper in", "other clinic", "average") keeps the comparison focus.
- **Consistency over 3 runs.** Turns 1 and 2 can list different subsets of the clinic table from run to run. The checks only need one number from each set, so this should not fail consistency, but the wording will vary.
- **Turn 4 wording.** This turn depends on the model saying what is missing. The rule exists and the passages make the gap clear, but this is the turn most likely to go wrong.
