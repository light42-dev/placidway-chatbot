## What was built

| File | What it does |
|---|---|
| `bot/pages.py` | The 7 allowed pages: key, URL, title, and the words in a question that point at each page. |
| `scripts/ingest.py` | The refresh command. Fetches the 7 pages (robots.txt checked, own User-Agent, one request a second), keeps the text inside `<main>`, cuts it into passages of about 1,200 characters at headings. If any page fails, the old index is kept. |
| `data/pages/*.txt`, `data/index.json` | The crawled text and the 176 passages, committed because the host has no disk. |
| `bot/retriever.py` | BM25 keyword search over the passages, in memory. Adds light stemming, a short synonym table ("how much" finds "Cost ... $18,995"), earlier user messages at lower weight for follow-ups, and a bonus for the page under discussion. |
| `bot/llm.py` | Calls Groq; on a rate limit or any other failure sends the same prompt to Gemini Flash-Lite. Plain HTTPS, no SDK. |
| `bot/chat.py` | Builds the prompt (rules + numbered passages + trimmed history), calls the model, and turns the model's final `USED: 1, 3` line into a `Source:` line. The URLs come from `bot/pages.py`, never from the model. |
| `bot/web.py` | Request validation and status codes: 400/422 bad input, 413 message over 4,000 characters, 429 when both providers are rate-limited, 502 when no model answers. |
| `bot/serve.py` | `python -m bot.serve --port 8101` |
| `api/chat.py` | Vercel entry point; a thin wrapper around `bot/web.py`. Not deployed or tested on Vercel. |
| `bot/config.py` | Keys and limits from the environment (`.env` locally). |

No new dependencies: the bot uses the standard library only.

Refresh: `python scripts/ingest.py`

## Things the next person should know

- **Rate limit.** This Groq key allows 8,000 tokens a minute and a reply uses about 1,900, so the suite's default 2-second pause gets HTTP 429 after four turns. `.env.example` now sets `BOT_MIN_INTERVAL_S=16`. With the 2-second pause the Gemini fallback did answer, but that reply took 7.1 s and failed the 5-second latency test.
- **Model names.** `llama-3.1-8b-instant` (Groq) and `gemini-2.5-flash` (Gemini) return 404 for these keys. The defaults are in `bot/config.py` and can be overridden with `GROQ_MODELS` (a comma-separated list, tried in order) and `GEMINI_MODEL`.
- **Groq blocks Python's default User-Agent** (HTTP 403, error 1010). `bot/llm.py` sends its own.
- **Other languages are not handled by retrieval.** The search matches English words, so a question in Spanish or Arabic will find little unless it names a page topic. Only the reply language is handled, by the prompt. Not tested here.
- **Citations depend on the model naming the passages it used.** If it names none but states a price, the best-matching page is cited. A reply with a fact, no price and no `USED` numbers would carry no link.
- **Token headroom is about 1,000.** Raising `CONTEXT_CHARS` (4,800) or `MAX_HISTORY_MESSAGES` (8) eats into the 3,000 limit.
