## (a) What changed, file by file

| File | Change |
|---|---|
| `bot/topic.py` (new) | **Topic-shift detection.** `current_focus()` wraps `find_focus_page()`. It drops the focus page (returns `None`) when the newest message (1) doesn't name the focus page's topic, (2) uses a subject word that appears in at least 2 passages but never on the focus page (synonym-table words such as "much" or "include" don't count), and (3) matches some other page at least 1.5 times better than the focus page (BM25 on the newest message alone). Before this, "Forget that. What's the cheapest ozone therapy you list" kept the anal-cancer package as focus (from turn 1), and the 3x focus bonus pushed every comparison-page price passage out of the context. |
| `bot/recall.py` (new) | `earlier_questions()`: the user messages cut from the trimmed history (the first one always kept, at most 4, each up to 150 characters) are added to the system prompt as a short list. At turn 6 the opening question "Price for anal cancer program." has been trimmed (`MAX_HISTORY_MESSAGES` = 8), so "the program I asked about first" could not be resolved. |
| `bot/medical.py` (new) | A code backstop for the doctor referral. If the newest message is medical (safe for me, skipping/stopping a treatment, chemo, radiation, insulin, diabetes, medication, side effects, pregnancy, and similar) and the reply names no doctor, oncologist or physician, "Please talk this over with your doctor." is added before the Source line. |
| `bot/chat.py` | (1) Uses `current_focus` in place of `find_focus_page` (one line plus imports). (2) Appends `earlier_questions(dropped)` to the system prompt. (3) Calls `add_doctor_referral` for medical questions. (4) Citation fallback widened: if the model names no passage but the reply states a figure, the best-ranked passage that contains one of the reply's numbers is cited. Before, this only happened when the reply contained `$`. It falls back to the top passage only when there is a `$`, as before. This covers "runs for 3 weeks" with `USED: none`. (5) One prompt sentence added to the prices rule: "Asked for the cheapest, give the one lowest matching listed price and its clinic." |

No changes to `bot/retriever.py`, `bot/pages.py`, ingestion or `data/`. I tried adding "cheapest"/"lowest" to the cost synonym group. That pushed the clinic listing passage ($110 Fizikon ozone) out of the context, so I reverted it.

**Prompt growth:** the fixed rules grow by 85 characters (about 21 tokens). The earlier-questions section appears only after the history has been trimmed: about 80 characters of heading plus the questions. At T02 turn 6 that is about 190 characters (about 48 tokens). My char/4 estimate for T02's largest prompt is about 2,430 tokens. Real tokenizer counts in earlier notes were about 2,200–2,400 for similar turns.

## (d) Risks and checks

- **Topic shift is a heuristic.** On sample follow-ups it kept the focus for "and the inpatient one?", "what's included", "what does the cheaper program cost", "how long is it" and "can my wife come with me". It dropped it for "videos", "medical director", "stem cell prices", "insurance" and "how many days". The last one is arguably wrong, but the earlier messages still count in retrieval at lower weight, so the package passages usually still appear. The margin on T02 turn 6 is not large: the score ratio is 1.31 against the 1.5 threshold, because "ask" (from "Frequently Asked Questions") is not on the anal page.
- **Consistency across 3 runs** compares dollar amounts. Turn 4 could mention $110 in one run and $110 plus $500–$1,500 in another. The new "cheapest" sentence is meant to keep it to one figure. A Gemini fallback run may still word it differently.
- **Medical referral guard:** a false positive (for example "is the hotel kidney-friendly") adds one harmless sentence. It does not remove advice-like phrases; it only adds the referral.
- **Checks I believe are wrong:** none that clearly block a correct answer. One possible trap: `medical_advice` includes `you should (… take …)`, so a correct "you should take this up with your doctor" would fail `no_medical_advice`. Not changed.
